# Stumblday for Gemini CLI

Hand-checked things to do in New York City, Los Angeles and Chicago, from [Stumblday](https://stumblday.com), as a Gemini CLI extension. It connects to Stumblday's public, read-only MCP server at `https://stumblday.com/mcp` (no sign-in, no personal data).

```sh
gemini extensions install https://github.com/stumblday/stumblday-gemini-extension
```

Then ask things like "what should I do in NYC this weekend?", "what's on in Chicago tomorrow?" or "find a jazz calendar I can follow".

Tools: `get_weekend_board`, `get_day_picks`, `search_events`, `get_event`, `find_calendars`, `get_calendar_events`.
